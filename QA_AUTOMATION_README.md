# Автоматизированное тестирование сайта-презентации

Набор скриптов на **Python 3.10+**, **Playwright** и отчёт в **Excel (.xlsx)** имитирует уровень Senior QA: ссылки, консоль, базовый HTML, a11y, адаптив, аккордеоны, переключатель языка, эвристики UI.

## Структура

| Файл | Назначение |
|------|------------|
| `test_website.py` | Точка входа: запуск проверок, скриншоты, код выхода |
| `report_generator.py` | Формирование `report_YYYYMMDD_HHMMSS.xlsx` (openpyxl) |
| `config.py` | URL, таймауты, viewport, селекторы, константы |
| `requirements.txt` | Зависимости pip |

## Установка

```powershell
cd путь\к\репозиторию
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
```

## Запуск

Одна команда (из корня проекта, где лежит `test_website.py`):

```powershell
python test_website.py
```

Опции:

- `--url https://arttatan.github.io/qa-engineer-presentation/` — другой URL (по умолчанию из `config.BASE_URL`).
- `--screenshots screenshots` — каталог для PNG (создаётся автоматически).
- `--skip-browser-install` — не вызывать автоустановку Chromium (удобно в CI, если браузер уже установлен).

Результаты:

- `report_YYYYMMDD_HHMMSS.xlsx` — в текущей рабочей директории.
- `screenshots/` — снимки при дефектах и эталонные по viewport.

## Код завершения

- **0** — нет дефектов с приоритетом **Critical** (подходит для зелёного CI).
- **1** — есть хотя бы один **Critical** (в консоль выводится явное сообщение).

## Пример содержимого отчёта (абстрактно)

### Лист «Общая сводка»

| Параметр | Значение |
|----------|----------|
| URL | https://arttatan.github.io/qa-engineer-presentation/ |
| Длительность (сек) | *пример: 45.2* |
| Всего проверок | *сумма пройденных и непройденных шагов* |
| Пройдено | *число* |
| Не пройдено | *число дефектов* |
| Критических проблем | *список или «— нет —»* |

Внизу блок **«Примечания»** — например, напоминание, что контраст текста/фона не проверяется автоматически глубоко (см. `config.A11Y_CONTRAST_NOTE`).

### Лист «Дефекты»

| ID | Тип | Приоритет | Описание | Локация | Скриншот | Рекомендация |
|----|-----|-----------|----------|---------|----------|--------------|
| D001 | консольная ошибка | High | error: ... | URL | screenshots/...png | Исправить JS... |
| D002 | адаптив | High | Горизонтальный скролл на viewport mobile | ... | ... | Убрать overflow-x... |

*(Реальные строки зависят от состояния сайта и сети.)*

## Примечания по проверкам

- **Битые ссылки:** внутренние якоря (`#id`), относительные и абсолютные URL; HEAD с переходом на GET при необходимости.
- **Консоль:** сообщения уровня `error` и `requestfailed` за время сессии.
- **Раскрывающиеся блоки:** нативные `<details>` (если есть) и кастомные `.experience-item` / `.case-item` на вашей вёрстке.
- **Контраст:** только текстовая заметка в сводке; для WCAG AA по контрасту используйте Lighthouse или axe.

## CI

Пример шага:

```yaml
- run: pip install -r requirements.txt
- run: playwright install chromium
- run: python test_website.py --skip-browser-install
```

При падении по коду **1** пайплайн можно помечать как неуспешный.
